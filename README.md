# 🦖 Dino Rhythm

Jogo offline de corrida rítmica em HTML/CSS/JavaScript.

## Como usar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Escolha uma música do seu celular/PC.
4. Selecione o modo de sincronização.
5. Clique em **COMEÇAR JOGO**.

## Modos
- **Automática:** analisa o áudio em tempo real usando Web Audio API e tenta detectar batidas.
- **BPM preciso:** gera as batidas matematicamente a partir do BPM e offset.
- **Batidas personalizadas:** informe os tempos em segundos separados por vírgula.

## Controles
- PC: `Espaço` ou `↑`
- Celular: toque no jogo
- Pausa: botão `Ⅱ`

A música escolhida pelo usuário é carregada localmente no navegador e não é enviada para servidor.
