# 🦖 Dino Rhythm v3

Versão com sincronização automática analisando a música inteira antes da partida. O modo automático detecta picos de áudio, estima BPM e preenche a grade rítmica para que os obstáculos continuem durante toda a música.

## Controles
- PC: Espaço/↑
- Celular: toque e segure para controlar melhor a altura do pulo
- Pausa: botão II

## Sincronização
- Automática: análise do arquivo + BPM estimado.
- BPM preciso: grade matemática a partir do BPM e offset.
- Batidas personalizadas: segundos separados por vírgulas.
